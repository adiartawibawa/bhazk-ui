# BhazkUI (Modular Blade UI Component Library)

BhazkUI adalah Pustaka komponen UI reusable yang dibangun di atas Laravel Blade, Livewire, Tailwindcss, DaisyUI 5, dan AlpineJS. Fokus utamanya adalah menyediakan komponen independen, bersih (clean code), dan mudah diintegrasikan ke dalam proyek Laravel baru maupun yang sudah ada tanpa perlu dependensi JavaScript yang berat.
